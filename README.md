# GRN Core

A modern, lightweight, and platform-independent tool for the
graphical construction and manipulation of Gene Regulatory Networks.

## How to use
The application can be accessed via GitHub Pages

## Development

### Requirements
- [NodeJS](https://nodejs.org/en/download)
- [Bun](https://bun.sh)

### Instructions
1. Clone this repo
2. Install dependencies
    ```sh
    bun install
    ```
3. Start the development server
    ```sh
    bun dev
    ```

## Tech Stack
- **Base template**
  - React
  - Vite *(with React Compiler Enabled)*
  - ESLint
